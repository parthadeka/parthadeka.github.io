Personal website — Partha Pratim Deka
=====================================

HOW TO PUBLISH
--------------
1. In your repo parthadeka/parthadeka.github.io, DELETE the old site files:
     index.html
     assets/            (the HTML5 UP "Prologue" theme folder)
     images/            (optional — the new images/ folder below replaces it)
2. Copy EVERYTHING inside this folder into the repo root.
3. Commit and push to the "main" branch.
4. GitHub Pages rebuilds automatically; the site is live at
   https://parthadeka.github.io within a minute or two.

WHAT IS HERE

  index.html          Home

  teaching.html       Teaching & mentorship

NOTES
-----
- Each page is a single self-contained HTML file. No build step, no
  dependencies. Edit the text directly in any editor.
- Fonts (Newsreader, IBM Plex Sans/Mono) load from Google Fonts.
- Image credits: the two MeerKAT photographs are SARAO's, credited in
  each figure caption and in the page footers.
- To replace the CV, overwrite cv.pdf keeping the same filename.
